# Changelog

The `executor-initialize` specification, released as the tags `executor-initialize/vX.Y.Z`.
The newest version comes first. A change to this directory adds the version
it will be released as.

## v0.1.0

- The first release: version 1 of the document, with its requirements
  `INIT-<n>`, each listed as not machine-checked because the specification's suite
  is S2's.
