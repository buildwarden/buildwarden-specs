# bootstrap-config, version 1

The policy document a collector serves and the executor reads through the relay.

| | |
|---|---|
| Seam | 6, the bootstrap config |
| Requirement identifiers | `BOOTCFG-<n>` |
| Roles | producer, relay, executor |
| Concept | [System trust](https://buildwarden.github.io/buildwarden/concepts/baseline.html#system-trust) in the BuildWarden book |
| Reference implementation | The `bootstrap/` package; the relay `cmd/relay` carries it and the executor `cmd/warden-io` reads it, in [buildwarden/buildwarden](https://github.com/buildwarden/buildwarden) |
| Status | Not yet released. While its release is `v0.x.y` this document may still change incompatibly; see Versioning |

The key words "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT", "SHOULD",
"SHOULD NOT", "RECOMMENDED", "NOT RECOMMENDED", "MAY" and "OPTIONAL" in this
document are to be interpreted as described in BCP 14 (RFC 2119, RFC 8174)
when, and only when, they appear in all capitals. A requirement is a
paragraph or list item that starts with its identifier in bold.
